# Screenshot (Personal Edition)

极简、稳定、快速、长期自用的 Windows 桌面截图工具。

> 本项目基于开源项目 [xushengfeng/eSearch](https://github.com/xushengfeng/eSearch) 进行二次开发与架构重构，遵循 GPL-3.0 许可证。详见 [NOTICE](NOTICE) 与 [LICENSE](LICENSE)。

---

## 核心定位

Screenshot 深度专注于单个核心场景：
**“看到屏幕内容 → 截图 → OCR / 搜索 / 翻译 / 贴图 / 保存”**

通过对原项目的架构瘦身与依赖剔除，彻底移除了屏幕录制、实时屏幕翻译、以图搜图、AI分析、复杂图片美化等外围功能，显著降低资源占用，提升启动与交互响应速度。

---

## 六大核心功能

### 1. 截图与图像标注
- **快速区域截屏**：精确框选屏幕任意区域。
- **图像标注与修饰**：内置画笔、几何图形、马赛克、高斯模糊、取色器。
- **历史操作**：支持多步撤销、重做。
- **复制与保存**：快捷复制到剪贴板或保存为本地图片。

### 2. 离线本地 OCR
- **纯本地运行**：内置 PaddleOCR ONNX 轻量模型，基于 CPU 本地推理，无网络依赖，毫秒级响应且保护隐私。
- **多功能联动**：识别出的文本支持富文本直接编辑、段落重组、一键复制、选词搜索及快捷翻译。

### 3. 便捷搜索
- **文本即搜**：OCR 选中文本后，一键唤起默认搜索引擎或自定义 URL 模板进行网页检索。

### 4. 快捷翻译
- **划词即译**：无缝对接识别出的文本，支持多语言快速翻译、一键复制结果，配置轻简。

### 5. 贴图（Pin）
- **多源置顶**：支持截屏直接贴图，或从系统剪贴板读取图片一键贴在桌面。
- **自由交互**：支持缩放、透明度调整、多张贴图并存与鼠标穿透。

### 6. 万向滚动截图
- **任意方向滚动拼图**：支持垂直、横向以及任意方向的滚动自动捕获。
- **智能拼接**：采用原项目成熟稳定的图像特征重叠拼接算法，自动平滑去重。
- **闭环产出**：拼接完成的长图可直接进行复制、本地保存、本地 OCR 识别或贴图。

## 快捷键

| 功能 | 默认快捷键 | 说明 |
| :--- | :--- | :--- |
| **截图** | <kbd>Alt</kbd> + <kbd>C</kbd> | 框选截屏并展示快捷标注栏 |
| **万向滚动截图** | <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd> | 捕获长图拼接 |
| **文字识别 (OCR)** | <kbd>Alt</kbd> + <kbd>V</kbd> | 直接打开识别主窗口 |
| **贴图** | <kbd>Alt</kbd> + <kbd>B</kbd> | 将剪贴板图片贴至屏幕最前端 |

*(快捷键均可在设置中心中自定义修改)*

## 开发者构建与运行

### 依赖环境
- Node.js >= 20
- pnpm >= 9

### 安装依赖
```bash
pnpm install
```

### 开发模式
```bash
pnpm run dev
```

### 代码规范与类型检查
```bash
pnpm run format      # Biome 格式化
pnpm run lint        # Biome 静态检查
pnpm run typecheck   # TypeScript 严格类型检查
```

### 生产打包
```bash
pnpm run build       # 编译主进程与渲染进程
pnpm run pack        # 生成 Windows 可执行便携目录
```
