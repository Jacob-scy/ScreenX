隐私与数据处理说明

客观、透明地向您说明 ScreenX 的数据处理机制、本地化架构与网络服务边界。

一、核心原则：默认本地处理

ScreenX 坚持以本地设备优先为核心设计理念。作为一款桌面工具，我们充分尊重并保护您的个人隐私与数据安全。

  • 截图采集： 截图操作通过 Windows 原生物理图形接口在您的本地内存中完成，不会在未经您明确操作的情况下上传或传输到任何远程服务器。
  • 本地离线 OCR： 内置的文字识别算法基于本地离线神经网络模型（PaddleOCR ONNX）在您的计算机本地 CPU/GPU 运行推理。识别全过程完全在本地闭环，断网状态下亦可正常使用。
  • 临时图片缓存： 截取及编辑中的图像文件仅保存在本地内存或系统标准临时目录中，不会备份或同步至外部云端。

二、客观界定：哪些场景会产生网络通信？

我们不作“绝对不产生任何网络流量”的虚假承诺，因为 ScreenX 包含部分需要与外部网络交互的辅助功能。当您主动使用以下功能时，会产生明确、可预期的网络通信：

  • 聚合搜索服务： 当您在选区后点击“搜索”或在识别结果中触发外部搜索时，软件将调用您的 Windows 默认浏览器打开对应搜索引擎网址（例如百度、Bing、Google 等）。搜索请求由对应搜索引擎根据其自身隐私政策处理。
  • 在线翻译服务： 当您使用屏幕翻译或划词翻译功能时，若选用了在线翻译引擎（如百度翻译、DeepL、Google 翻译等），待翻译文本将发送至您所选定的第三方翻译服务商接口。
  • 安装包与元数据下载： 本网站页面访问、最新版本信息获取（latest.json）以及安装包文件分发托管于 Cloudflare Pages 与 Cloudflare R2，网络传输遵从标准 CDN 日志与安全策略。

三、本地配置与持久化存储

ScreenX 的偏好设置（如快捷键配置、界面语言、窗口位置偏好等）以纯文本 JSON 格式安全保存在您的本地用户目录中：

  • 标准存储路径：%APPDATA%\screenx（安装版）或程序所在目录（绿色版数据隔离模式）。
  • 软件不提供亦不强制要求任何用户账号体系，不记录用户身份标识。

四、无跟踪器与无广告承诺

ScreenX 恪守开源纯粹体验：

  • 绝无任何形式的第三方商业广告 SDK 或推广插件；
  • 绝无 Google Analytics、友盟、百度统计等隐蔽用户行为画像或遥测探针；
  • 绝不擅自扫描您的硬盘文件、注册表隐私信息或后台监听麦克风、摄像头。

五、开放审计与 GPL-3.0 源代码

作为遵循 GNU General Public License v3.0 (GPL-3.0) 的自由开源软件，ScreenX 的全部源代码均已公开开放。任何用户或安全研究人员均可自由审查项目源码中的网络请求、数据存储及调用逻辑，确保代码行为与本说明完全一致。
