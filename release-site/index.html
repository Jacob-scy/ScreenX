FAQ

常见问题与解答

快速了解关于 ScreenX 的核心使用机制与技术细节。

为什么需要 Windows 10 (1809+) 或 Windows 11 系统？
ScreenX 的屏幕截取模块深度调用了 Windows 现代化物理缓冲区捕获接口（Win32 GDI Physical Buffer），以保障在高刷新率显示器及高 DPI 缩放场景下无黑屏、无撕裂截取。这些底层接口在 Windows 10 1809 及更高版本中具备最佳稳定性与系统支持。
截图内容会上传到云端服务器吗？
不会。ScreenX 坚持本地设备优先原则。您截取的屏幕图像仅存在于本地内存和系统临时目录中，绝不会在后台自动上传或回传至任何远程云端。详细信息请参阅我们的隐私说明。
离线 OCR 文字识别是否需要连接互联网？
完全不需要。ScreenX 内置了 PaddleOCR ONNX 轻量化神经网络模型，文字识别计算完全由您本地计算机的 CPU 完成推理，断网环境下依然可以正常识别中英文及标点。
如何修改默认截图全局快捷键（Alt + C）？
右键点击 Windows 任务栏右下角通知区域的 ScreenX 托盘图标，在弹出菜单中点击「设置」，切换至快捷键选项卡即可自由修改截图呼出热键或为其他常用功能绑定快捷操作。
安装版与绿色便携版有什么区别？
安装版（EXE）提供标准的向导安装、桌面和开始菜单图标注册以及 Windows 系统控制面板的卸载入口；绿色便携版（ZIP）解压即用，所有运行时数据可完全存放在独立目录中，方便放入 U 盘移动携带。两者的核心功能、性能与版本完全一致。
如何彻底卸载 ScreenX？
若为安装版，请前往 Windows「设置」>「应用」>「安装的应用」，搜索「ScreenX」点击「卸载」并跟随向导移除即可；若为绿色便携版，只需在任务栏托盘中退出软件后，直接将程序解压文件夹移入回收站。
为什么首次运行时 Windows Defender SmartScreen 会提示安全警告？
作为独立维护的自由开源项目，ScreenX 尚未购置商业企业级 EV 数字签名证书。Windows SmartScreen 在识别到新发布且尚未累积全网信誉的二进制程序时会默认弹出提示。只要您确认安装包下载自官方正版渠道（https://screenx.jacobscy.xyz/ 与 https://download.jacobscy.xyz/），点击提示窗口中的「更多信息」，随后点击「仍要运行」即可正常启动。
