ScreenX v1.0.0 发布说明

专为 Windows 10/11 设计的轻量级原生截图与桌面效率工具首个正式公开版本。

一、版本基本信息

  • 软件名称： ScreenX
  • 当前版本： v1.0.0 (正式公开版)
  • 发布时间： 2026 年 9 月
  • 适用平台： Windows 10 (1809 以上) / Windows 11 · x64 架构
  • 分发加速： Cloudflare R2 + 全球 CDN 边缘节点
  • 开源协议： GNU General Public License v3.0 (GPL-3.0)

二、核心功能支持

  • 原生截图体验： 深度优化的 Win32 GDI 物理缓冲捕获技术，支持高 DPI、多显示器精确选区。
  • 离线本地 OCR： 内置 PaddleOCR ONNX 轻量模型，纯本地推理提取图像文字，无需上传云端。
  • 一键划词搜索： OCR 选区文本一键流转到默认浏览器搜索引擎快速检索。
  • 快捷划词翻译： 选中文本即时呼出翻译面板，支持用户按需配置多翻译源对照。
  • 灵动桌面贴图： 截图或剪贴板图片快速钉在屏幕最前端，支持无级缩放与标注。
  • 全方向长截图： 支持横向与纵向自由滚动，特征重叠区域自动无缝拼接。

三、下载与分发文件

  • 官方安装包： ScreenX-Setup-1.0.0.exe (约 224.5 MB，推荐普通用户下载，带桌面快捷方式与卸载向导)
  • 绿色便携版： ScreenX-1.0.0-win.zip (约 210.9 MB，解压即用，适合免安装体验)
  • GPL 纯净源码包： ScreenX-1.0.0-source.zip (约 32.4 MB，严格剔除构建缓存的合规完整源码归档)
  • 版本元数据 API： latest.json

四、文件完整性校验 (SHA-256)

为保障下载文件的完整性，防止因网络传输损坏或篡改，建议在下载后比对对应的 SHA-256 哈希值：

d7c94709408f765ee853aa6943bd057ea1ad32346c5bcb7f26e88d07460f9446 ScreenX-Setup-1.0.0.exe e8fbdd5001839910b90d1e4d679ddc3ccd1fcbd7f3ad385985f30736240b6f72 ScreenX-1.0.0-win.zip 12105c84bae213b4dda2429fbde138f92ef8089d808c920b61d33a8de429b4df ScreenX-1.0.0-source.zip

您可以通过 Windows PowerShell 快速验证下载文件的哈希值：
Get-FileHash <下载的文件路径> -Algorithm SHA256
